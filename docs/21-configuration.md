# Configuration of the chain

Generated by `python tools/khg_pipeline.py config catalogue` from `tools/pipeline/schema.py`; do not edit by hand.

Three layers, later wins: `pipeline.yaml` (+ `pipeline.local.yaml`, not tracked) for all KHG; `sites/<folder>/khg.yaml`, generated by `init` and never edited; `sites/<folder>/overrides.yaml`, hand-written exceptions with a reason and a date. In `overrides.yaml`, `steps:` takes any key of the step sections below for that KHG only, e.g. `steps: {delineation: {min_area_km2: 50}, pump: {set: {interventions.held_target: 0.6}}}`. `pump.set` takes any key of repeat-pump's run config (`repeat_pump.core.config.Config`).

Check a KHG before running: `config validate --khg <code>`; see what applies and from which file: `config show --khg <code>`.

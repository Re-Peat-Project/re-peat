# Pump settings (repeat-pump run config)

Generated by `python tools/khg_pipeline.py config catalogue` from `repeat_pump.core.config.Config` and
`repeat-pump/configs/proposed_defaults.yaml`; do not edit by hand.

Any key below goes under `pump.set` (dotted), nationally or for one KHG:

```yaml
pump:
  set:
    optimise.n_blocks: 15
    interventions.held_target: 0.6
```

Precedence: your `pump.set` > the chain's (column *Chain*) > the proposed defaults (column *Proposed*,
filled only where the run config leaves a value empty) > the model default. *Proposed* values are suggestions, not team
decisions; each comment says how sure it is (HIGH, MED, LOW, POLICY) and where it comes from.
`inputs.*` and the run's name, output file and CRS are set by the chain from the KHG folder and are not listed.

Column *Chain* is what the chain sets for every KHG: `pipeline.yaml` `pump.set` (bold) wins over what the config builder
fills from the KHG folder.
